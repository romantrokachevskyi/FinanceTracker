# Docs index

`AGENTS.md` is the entry point and routes by task; this lists every doc.
`docs/` is also the GitHub Pages content folder: `index.html` and `privacy/`
are published pages, not agent docs.

- [AGENTS.md](../AGENTS.md) — read first: contracts, verification, routing
- [project](../.agents/project.md) — read when changing behaviour, storage, calculations, localization, accessibility or layout
- [workflow](../.agents/workflow.md) — read when implementing or reviewing a change
- [checks](../.agents/checks.md) — read when editing `scripts/` or adding test coverage
- [android-release](../.agents/android-release.md) — read when changing packaging, signing, app identity or store artifacts
- [ads](../.agents/ads.md) — read when changing the banner, visit counter, consent, or anything about the privacy posture
- [RELEASE](store/RELEASE.md) — read when publishing to Google Play or AdMob: the ordered runbook
- [verification](store/verification.md) — read when claiming a release step works: what ran on which build, what is still open
- [data-safety](store/data-safety.md) — read when answering Play Console declarations or changing what the app or SDK collects
- [listing-en](store/listing-en.md) / [listing-uk](store/listing-uk.md) — read when editing store listing text
- [release-notes](store/release-notes.md) — read when preparing a Play release
