# До зарплати

## Short description

Скільки можна витрачати щодня до зарплати. Працює офлайн, без реєстрації.

## Full description

«До зарплати» відповідає на одне запитання: скільки грошей можна витрачати
сьогодні, щоб вистачило до наступної зарплати.

Без категорій, без чеків, без підключення до банку. Ви вводите поточний баланс
і дату наступної зарплати — застосунок рахує безпечну суму на день.

Як це працює:

1. Створіть план: вкажіть поточний баланс і дату наступної зарплати.
2. Дивіться щоденну суму та скільки мало б залишитися за планом на сьогодні.
3. Оновлюйте фактичний баланс, коли зручно. План не скидається — ви бачите,
   чи є запас, чи є відставання.
4. У день зарплати починайте новий період.

Чому саме так:

• Ваші суми залишаються на пристрої. Застосунок нікуди їх не надсилає, усі
  розрахунки виконуються локально й працюють без мережі.
• Без облікових записів. Нічого не треба реєструвати чи підтверджувати.
• Без власної аналітики й трекерів. Застосунок безкоштовний завдяки одному
  невеликому банеру, який з'являється лише після десяти днів користування.
• Дані зберігаються лише на вашому пристрої й видаляються разом із
  застосунком.
• Українською та англійською мовами.
• Зроблено для телефона: великі елементи керування, підтримка масштабування
  та зчитувачів екрана.

Застосунок виконує арифметику з числами, які ви вводите самі. Він не є
банківською послугою, не дає інвестиційних порад і не має доступу до ваших
рахунків.
